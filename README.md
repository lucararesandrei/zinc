# Zinc

Zinc is a lightweight terminal text editor written in C, based on the Kilo editor. It keeps a small and direct codebase while developing its own customizable, Vim-inspired direction.

The current version supports terminal-based file editing, search, C/C++ syntax highlighting, configurable defaults, and regression tests.

More updates to come.

## Build and run

```sh
make
./zinc [file]
```

Run tests with:

```sh
make test
```
